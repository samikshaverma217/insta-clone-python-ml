# 📸 InstaClone - Python + ML

Instagram jaisa app jo Python, Streamlit aur Machine Learning se banaya hai.
Sirf dikhne wala clone nahi, dimaag wala clone hai!

### 🔗 Live Demo
Yaha apna Streamlit link daalna - jab deploy ho jaye

### ✨ Features

**1. 📸 Feed / Photos**
- Insta jaisa Feed with Photos, Likes, Captions
- Stories style layout

**2. 🎬 Reels / Videos**
- Video Reels with Play button
- Like + Comments count

**3. 🤖 ML - Recommendation System**
- User ki pasand (Travel / Food / Fitness) ke hisab se post suggest karta hai
- ML Score % me batata hai - kitna match hai

**4. 🤖 ML - Spam Comment Detector**
- Comment me `free followers`, `click link` jaisa likho to ML usko SPAM bol deta hai
- Safe comment ko GREEN me SAFE batata hai

**5. 🏷️ ML - Hashtag Suggester**
- Photo ki category select karo, ML trending hashtags suggest karega

### 🛠️ Tech Stack
- **Python** - Main Language
- **Streamlit** - Web App / UI
- **Pandas** - Data Handling
- **Machine Learning** - Recommendation + Spam Detection (Rule-based ML)
